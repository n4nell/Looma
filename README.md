# Hai, selamat datang di Looma! ✨

Looma adalah ruang bermain kreatif buat kamu yang suka menuangkan ide, bikin karya, dan berbagi inspirasi. Mau menulis, menggambar, merangkai ide, atau mencoba tantangan seru? Semuanya bisa dimulai dari sini. 🎨💡

## Di Looma, kamu bisa...

- **Bikin karya sesukamu** — tulis cerita, gambar sesuatu, atau susun papan ide.
- **Ikut Truth or Dare** — jawab jujur atau ambil tantangan kreatif hari ini. 🎲
- **Bagikan ke feed** — tunjukkan karyamu dan lihat kreasi teman-teman Looma.
- **Saling menyemangati** — kasih like, tinggalkan komentar, dan pin komentar favoritmu.
- **Kenalan dengan kreator lain** — temukan orang-orang dengan ide dan karya yang seru.
- **Simpan dulu, lanjut nanti** — drafmu tetap siap saat inspirasi datang lagi. 🌱

Nggak harus sempurna untuk mulai. Buka Looma, pilih ide pertamamu, dan biarkan kreativitasmu jalan-jalan! 🚀
